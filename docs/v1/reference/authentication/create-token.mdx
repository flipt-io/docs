title: "Create Token"
openapi: "https://raw.githubusercontent.com/flipt-io/flipt/main/openapi.yaml POST /auth/v1/method/token"
---

<RequestExample>

```bash cURL
curl --request POST \
  --url http://localhost:8080/auth/v1/method/token \
  --header 'Content-Type: application/json' \
  --header 'Accept: application/json' \
  --header 'Authorization: Bearer <token>' \
  --data '{
  "description": "<description>",
  "name": "<name>"
}'
```

</RequestExample>

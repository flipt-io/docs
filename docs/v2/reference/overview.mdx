---
title: API Overview
description: Learn how to interact with the Flipt REST API to manage environments, branches, namespaces, flags, and segments, and evaluate feature flags programmatically.
---

Flipt's API is the primary way to interact with Flipt outside of the UI. You can use it to manage environments, branches, namespaces, flags, and segments, and to evaluate flags.

The Flipt UI is backed by this same API. Anything you can do in the UI you can also do via the REST API.

The [management REST API](https://raw.githubusercontent.com/flipt-io/flipt/refs/heads/v2/rpc/v2/environments/openapi.yaml), [evaluation snapshot REST API](https://raw.githubusercontent.com/flipt-io/flipt/refs/heads/v2/rpc/v2/evaluation/openapi.yaml), and [evaluation REST API](https://raw.githubusercontent.com/flipt-io/flipt/refs/heads/v2/rpc/flipt/openapi.yaml) are documented using the OpenAPI v3 specification. Server-side evaluation uses the same `/evaluate/v1` endpoints as Flipt v1.
